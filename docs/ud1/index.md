# <span class="ud ud1">UD1</span> Introdución ao Big Data

**Novo paradigma e metodoloxías de traballo** · 18 sesiones (15 h) · semanas 1–3 · 1ª evaluación

En esta unidad entendemos qué es Big Data y por qué exige otra forma de trabajar, y dejamos preparado el **entorno de trabajo** que usaremos todo el curso. Al acabar, cada persona tendrá el mismo entorno funcionando y sabrá usarlo.

## Resultados de aprendizaje

| RA | Criterios de evaluación |
|---|---|
| **RA1.** Aplica técnicas de análisis de datos que integran, procesan y analizan la información, adaptando e implementando sistemas que las utilicen. | a) conceptos de matemática discreta, lógica algorítmica y complejidad · e) objetivos, prioridades y organización del tiempo · g) criterios de coste y calidad de un sistema Big Data |
| **RA3.** Gestiona y almacena datos facilitando la búsqueda de respuestas en grandes conjuntos de datos. | b) extraer valor de los datos con tecnologías eficientes · c) la revolución digital exige almacenar y procesar grandes cantidades de datos · e) habilidades científicas en entornos multidisciplinares |

## Contenidos

1. **Big Data:** el nuevo paradigma, las V (volumen, velocidad, variedad, veracidad, valor) y la revolución digital.
2. **Ecosistema y arquitecturas** Big Data (Lambda y Kappa). Perfiles profesionales.
3. **Fundamentos:** matemática discreta, lógica algorítmica y complejidad computacional (notación O).
4. **Costes y calidad** de un sistema Big Data. Planificación de un proyecto de datos.
5. **Entorno de trabajo:**
    - Linux en Windows con WSL.
    - Terminal bash y SSH.
    - Entornos de Python con Miniconda, pip, venv y poetry.
    - Notebooks con JupyterLab y Markdown.
    - Control de versiones con Git y GitHub.
    - Contenedores con Docker.
6. **Repaso de Python** aplicado al tratamiento de texto.
